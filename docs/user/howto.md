# How do I…
<!-- order: 0 -->

Short answers. Each links to the page with more.

- **Set the panel up from scratch?** [Settings → Set up](#settings/setup) goes through each step in order. See
  [Setting up](#help/setup).
- **Set the panel up by talking to an AI assistant?** [Settings → AI assistant](#settings/assistant): create a
  token, paste the snippet into Claude Desktop or Claude Code, then ask. Optional, but it makes the rest easy. See
  [AI assistants](#help/mcp).
- **Watch the robot on camera with a pause button in reach?** Live → **Camera** (beside the title).
- **See where the robot is and what it is doing?** [Live](#live). The dot is sky blue with a pulsing ring while it
  works and amber when it is held mid-plan. See [Live](#help/live).
- **Start, pause or send it home from the panel?** Switch control on in [Settings → Safety](#settings/safety) (you
  type ENABLE), then use the Control card on Live. See [Safety](#help/safety).
- **Check whether it would start right now, without starting it?** The "Ready to start" line on Live and Schedule
  runs every check and sends nothing.
- **Mow on a schedule?** [Schedule](#schedule): add a window (days, times, plan). The panel asks you to confirm each
  start unless you tick auto-start. See [Schedule](#help/schedule).
- **See how the last mow went?** [Runs](#runs), then pick the run: coverage, gaps, planned vs driven, problems.
- **Find where the robot keeps getting stuck?** Map tool **Problem areas** on Live or on a run.
- **Add a no-go zone?** [Map Studio](#studio) → + No-go, draw it, then Send in the draft at the top of Yard. Map writing must be on. See
  [Map Studio](#help/studio).
- **Back up the robot's map?** Map Studio → History → Save now.
- **Get a better aerial photo under the map?** [Settings → Map imagery](#settings/imagery): cards are sharpest
  first, in cm per pixel (7–10 cm shows pavers, 30 cm soft edges, 60 cm a blur). See [Map imagery](#help/imagery).
- **Get the most detailed map there is?** Look at the samples of the sharpest few; if the best free one is 30 cm or
  coarser, add a key or your county's own service, or ask an [AI assistant](#help/mcp) to find it for you.
- **Line the photo up with the map?** [Settings → Map imagery](#settings/imagery) → Align on the map: pick a spot on the map, then the same spot in the
  photo. Two or more pairs fix rotation too.
- **Know when the lawn is dry enough?** [Settings → Lawn conditions](#settings/lawn) (Tempest weather station).
- **Get alerts on my phone?** [Settings → Notifications](#settings/alerts) (a Home Assistant notify service or a
  webhook), then send a test.
- **Track blade changes and cleaning?** [Robot → Maintenance](#maintenance): set each item's interval and mark it done when
  you do the job.
- **Find out what the panel cannot do yet?** [Not capable of yet](#help/not-yet).
- **See what changed in this version?** [Changelog](#help/changelog).
- **Switch control or map writing on or off quickly?** The switch in the bar at the top of every page (map writing
  while Map Studio is open). Switching on still asks you to type ENABLE.
- **Use a light screen?** The sun / moon button in the top-right corner switches between light and dark for this
  browser. To follow your device again: [Settings → This panel](#settings/panel) → Theme → System.
